# Часть 59. Список продуктов (I) | Список продуктов по категориям
В этой части мы создадим динамическую страницу со списком товаров, которая будет загружать товары по URL-адресу категории (например, /t-shirts, /shirts). Эта реализация позволит:
- Показать товары из выбранной категории и ее подкатегорий
- Используйте ресурсную маршрутизацию (метод index() в контроллере)
- Используйте вручную созданный класс обслуживания для бизнес-логики
- Используйте хорошо структурированные представления Blade, включая повторно используемые фрагменты
## Шаг 1: Создайте ProductService вручную
Путь: **app/Services/Front/ProductService.php**

Цель:

Обрабатывает логику, связанную с продуктами, например, выборку продуктов по категориям, подкатегориям и разбиение результатов на страницы.
```php
namespace App\Services\Front;

use App\Models\Category;
use App\Models\Product;

class ProductService
{
    public function getCategoryListingData($url): array
    {
        $categoryInfo = Category::categoryDetails($url);

        $products = Product::with('product_images')
            ->whereIn('category_id', $categoryInfo['categoryIds'])
            ->where('status', 1)
            ->paginate(30);

        return [
            'categoryDetails' => $categoryInfo['categoryDetails'],
            'categoryProducts' => $products,
        ];
    }
}
```

## Шаг 3: Определите динамические маршруты категорий в web.php
```php
use App\Models\Category;
use App\Http\Controllers\Front\ProductController as ProductFrontController;

$catUrls = Category::where('status', 1)->pluck('url')->toArray();
foreach ($catUrls as $url) {
    Route::get("/$url", [ProductFrontController::class, 'index']);
}
```
Это позволит создать удобные URL-адреса категорий, например /t-shirts, /kurta и т.д.

Полная группа Front будет выглядеть следующим образом:
```php
Route::namespace('App\Http\Controllers\Front')->group(function () {
    Route::get('/', [IndexController::class, 'index']);

    $catUrls = Category::where('status', 1)->pluck('url')->toArray();
    foreach ($catUrls as $url) {
        Route::get("/$url", [ProductFrontController::class, 'index']);
    }
});
```
## Шаг 4: Добавьте функцию categoryDetails в модель категории.
```php
public static function categoryDetails($type): array
{
    $getCategories = Category::with(['subcategories.subcategories'])
        ->whereNull('parent_id')
        ->where('status', 1);
    if ($type == 'Front') {
        $getCategories = $getCategories->where('menu_status', 1);
    }
    return $getCategories->get()->toArray();
}
```
## Шаг 5: Обновление функции index в ProductController
```php
namespace App\Http\Controllers\Front;

use App\Http\Controllers\Controller;
use App\Models\Category;
use App\Services\Front\ProductService;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Route;

class ProductController extends Controller
{
    public function __construct(
        protected ProductService $productService
    ) {}

    public function index()
    {
        $url = Route::current()->uri();
        $category = Category::where('url', $url)->where('status', 1)->first();
        if (!$category) abort(404);
        $data = $this->productService->getCategoryListingData($url);
        return view('front.products.index', $data);
    }
}
```
