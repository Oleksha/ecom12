# Часть 60. Список продуктов (II) | Хлебные крошки и навигация по категориям
В этой части мы:
- Отображать навигационную цепочку категорий на странице со списком товаров.
- Показывать пагинацию Laravel для списков товаров.
## Шаг 1: Обновите функцию сведений о категории в модели категории
Мы обновим функцию «Подробности категории» в модели «Категория» для:
* Извлечь текущую категорию и ее подкатегории.
* Создайте динамичную навигационную цепочку.
  + Если выбрана основная категория, например «Рубашки», навигационная цепочка будет выглядеть так: Главная > Рубашки
  + Если выбрана подкатегория, например, «Форменные рубашки», навигационная цепочка будет выглядеть так: Главная > Рубашки > Форменные рубашки

**Обновить код для categoryDetails:**
```php
public static function categoryDetails($url): ?array
{
    $category = self::with('subcategories:id,parent_id,name')
        ->where('url', $url)
        ->where('status', 1)
        ->first();
    if (!$category) return null;
    $categoryIds = [$category->id];
    foreach ($category->subcategories as $subcategory) {
        $categoryIds[] = $subcategory->id;
    }

    $breadcrumbs = '<div class="px-2 py-1 mb-1" style="background-color: #f9f9f9">';
    $breadcrumbs .= '<nav aria-label="breadcrumbs">';
    $breadcrumbs .= '<ol class="breadcrumb mb-0" style="background-color: #f9f9f9"; --bs-breadcrumb-divider:\'>\';">';
    $breadcrumbs .= '<li class="breadcrumb-item"><a href="' . url('/') . '" class="text-dark text-decoration-none">Home</a></li>';
    if ($category->parent_id == 0) {
        $breadcrumbs .= '<li class="breadcrumb-item fw-bold active" aria-current="page">' . $category->name . '</li>';
    } else {
        $parentCategory = self::select('name', 'url')
            ->where('id', $category->parent_id)
            ->first();
        if ($parentCategory) {
            $breadcrumbs .= '<li class="breadcrumb-item fw-bold"><a href="' . url($parentCategory->url) . '" class="text-dark text-decoration-none">' . $parentCategory->name . '</a></li>';
        }
        $breadcrumbs .= '<li class="breadcrumb-item fw-bold active" aria-current="page">' . $category->name . '</li>';
    }
    $breadcrumbs .= '</ol>';
    $breadcrumbs .= '</nav>';
    $breadcrumbs .= '</div>';

    return [
        'categoryIds' => $categoryIds,
        'categoryDetails' => $category,
        'breadcrumbs' => $breadcrumbs
    ];
}
```

## Шаг 3: Добавьте пагинацию Laravel для товаров
Обновите метод **getCategoryListingData** в **ProductService** (или аналогичной службе/контроллере), чтобы добавить пагинацию:

**Обновить контроллер/метод службы:**
```php
public function getCategoryListingData($url): array
{
    $categoryInfo = Category::categoryDetails($url);
    $products = Product::with('product_images')
        ->whereIn('category_id', $categoryInfo['categoryIds'])
        ->where('status', 1)
        ->paginate(9);

    return [
        'categoryDetails' => $categoryInfo['categoryDetails'],
        'categoryProducts' => $products,
        'breadcrumbs' => $categoryInfo['breadcrumbs'],
    ];
}
```
